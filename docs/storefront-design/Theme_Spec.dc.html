API yang perlu ditambah

APIKegunaan
GET /api/theme/publishedFrontend membaca tema aktif (boleh di-cache, dibersihkan saat publikasi)
GET /api/admin/theme/draftBaca draf
PUT /api/admin/theme/draftSimpan draf (auto-save)
POST /api/admin/theme/validateMengembalikan kontras setiap pasangan dan saran perbaikan
POST /api/admin/theme/preview-linkMembuat link pratinjau uji berbatas waktu
POST /api/admin/theme/publishPublikasi hanya jika validasi lolos; mengembalikan nomor versi
GET /api/admin/theme/versionsRiwayat versi
POST /api/admin/theme/versions/{id}/restoreKembalikan jadi draf, lalu lewati alur publikasi
GET /api/admin/theme/presetsDaftar tema bawaan (bisa ditambah)

Aturan validasi kontras (frontend langsung + backend cek ulang sebelum publikasi)

CekAturan
Teks / latartext, text-2, text-3 terhadap bg, surface, bg-soft ≥ 4.5:1
Tombolon-primary terhadap primary ≥ 4.5:1; sistem otomatis memilih abu gelap atau putih, jika keduanya gagal publikasi diblokir
Link & tombol outlineprimary-strong terhadap surface ≥ 4.5:1
Ikon, border inputborder-strong terhadap surface ≥ 3:1
Warna statussuccess / warning / error / info / live terhadap teks putih dan surface ≥ 4.5:1, warnanya harus bisa dibedakan (dan selalu dengan ikon + teks)
Mode kontras tinggiNilai override terpisah, semua pasangan ≥ 7:1

Mekanisme publikasi

  • Ubah → pratinjau langsung (hanya di admin) → simpan draf → link pratinjau uji (berbatas waktu, tidak diindeks) → publikasi / batal / kembalikan versi sebelumnya
  • Publikasi bersifat atomik: berganti hanya jika validasi dan penyimpanan berhasil; jika gagal situs live tetap versi valid terakhir dan menampilkan alasan
  • CSS tema frontend punya nilai bawaan (Peach + Putih); jika pengaturan tidak terbaca pakai bawaan, tidak akan tanpa warna atau rusak
  • Hanya peran "Brand Admin" yang bisa publikasi; semua publikasi dicatat
