Aturan
・Semua batas dan selisih di teks frontend adalah variabel: {threshold}, {remaining} = threshold − subtotal (dibulatkan, tidak pernah negatif).
・Frontend membaca satu API pengaturan (mis. GET /settings/shipping → threshold, methods, startAt, endAt, active), tidak ada angka tertulis mati.
・Ongkir dan status gratis ongkir dihitung ulang backend saat pesanan dibuat; tampilan frontend dan total checkout mengikuti backend, agar tidak terjadi "tampil gratis ongkir tapi checkout kena ongkir".
・Tentukan di aturan admin apakah subtotal dihitung setelah atau sebelum diskon, dan tampilkan di pratinjau.
・Metode pengiriman yang tidak termasuk promo (mis. kirim ke rumah) menampilkan ongkir asli, tanpa tulisan gratis ongkir.
・Setelah pengaturan diubah, cache frontend berlaku maks. [60] detik.
