Aturan frontend
・Modul dimatikan → seluruh blok hilang di frontend, jarak atas-bawah menyatu, tanpa ruang kosong.
・Modul dimatikan → API tidak mengirim modul itu, frontend tidak memuat gambar & datanya.
・Modul kosong (mis. tidak ada produk baru) → otomatis disembunyikan di frontend, admin mendapat peringatan.
・Hero, kotak cari, blok CS, dan footer adalah blok tetap, tidak bisa dimatikan (CS prioritas).
・Bisa pratinjau versi mobile & desktop sebelum publikasi.
